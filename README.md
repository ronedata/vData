# ভোটার তালিকা — সার্ভারবিহীন সংস্করণ

খাঁটি HTML + CSS + JavaScript। **পাইথন বা কোনো সার্ভার লাগে না।**

## চালানো

**`index.html`-এ ডাবল-ক্লিক করুন।** ব্যস।

কাজ করে Chrome, Edge, Firefox — সবগুলোতেই, অফলাইনেও।

## যেভাবে খুঁজবেন

আগের মতোই: জেলা → আসন → উপজেলা → ইউনিয়ন → **ভোটার এলাকা** (পাঁচটিই লাগবে),
তারপর নাম / পিতা / মাতা / জন্ম তারিখ / পেশা / লিঙ্গ দিয়ে অনুসন্ধান করুন।

ভোটার নম্বর দিয়ে খোঁজার ঘর রাখা হয়নি — অনেকেই নিজের নম্বর জানেন না।
নম্বরটি ফলাফলে ও কার্ডে দেখা যায়।

সারিতে ক্লিক করলে পূর্ণ তথ্য ও ঠিকানাসহ কার্ড খোলে।

## ভিতরের গঠন

```
ওয়েব\
├── index.html          পাতা
├── app.js              খোঁজা ও দেখানো — সবটাই ব্রাউজারে
├── style.css           সাজ
├── vendor\             Bootstrap 5 (নিজস্ব কপি, ইন্টারনেট ছাড়াও চলে)
└── data\
    ├── index.js        আসন → উপজেলা → ইউনিয়ন → এলাকার গাছ (১৪৯ KB)
    └── area\
        ├── 470.js      এক এলাকার সব ভোটার
        └── …           মোট ১৩৪৭টি ফাইল, ২৩৭ MB
```

এলাকা বাছলে **শুধু ওই একটা ফাইল** নামে (গড়ে ১৭০ KB, gzip হলে ~৩৪ KB)।
পুরো ২৩৭ MB কখনোই নামে না।

### ডেটা কেন `.js`, `.json` নয়

ব্রাউজার `file://` থেকে `fetch()` আটকায় (CORS), কিন্তু `<script src>` আটকায় না।
তাই ডেটা `window.__AREA__ = {...}` আকারে `.js` ফাইলে — ফলে **ডাবল-ক্লিকেও চলে,
ওয়েবসার্ভারেও চলে**।

### সারির গঠন

জায়গা বাঁচাতে প্রতিটি সারি অবজেক্ট নয়, অ্যারে:

```
[ক্রমিক, নাম, পিতা, মাতা, পেশা_ক্রম, জন্ম_iso, লিঙ্গ_ক্রম, ঠিকানা_ক্রম, ভোটার_নং]
```

পেশা ও ঠিকানা এলাকাভিত্তিক তালিকায় একবার লেখা থাকে, সারিতে শুধু ক্রম নম্বর।
এতে রেকর্ডপ্রতি ৪৩১ → ১৬৮ বাইটে নেমেছে।

## ওয়েবে তুলতে চাইলে

`ওয়েব\` ফোল্ডারের সবটা যেকোনো স্ট্যাটিক হোস্টে দিলেই চলে — GitHub Pages,
Netlify, Cloudflare Pages। GitHub Pages-এর সীমার মধ্যেই থাকে
(ফাইল <১০০ MB · সাইট <১ GB · মাসে ১০০ GB)।

> **সাবধান:** এটি ১৩.৬ লাখ জীবিত মানুষের নাম, পিতা-মাতার নাম, জন্মতারিখ ও
> ঠিকানা। উন্মুক্ত ওয়েবে তুললে যে কেউ — সার্চ ইঞ্জিনসহ — সব পেয়ে যাবে।
> নিজের কাছে রাখা বা পাসওয়ার্ড দিয়ে ঢাকা হোস্টে রাখাই নিরাপদ।

## ডেটা আবার বানাতে হলে

```
python কাজের-নথি\scripts\build_static.py             # সব
python কাজের-নথি\scripts\build_static.py --seat 2    # এক আসন
python কাজের-নথি\scripts\build_static.py --limit 5   # পরীক্ষা
```

উৎস `ডাটাবেস\Bagerhat.db`। পাইথন শুধু এই ধাপেই লাগে — অ্যাপ চালাতে নয়।

## পাইথনের অ্যাপের সাথে তুলনা

| | `অ্যাপ\` (পাইথন) | `ওয়েব\` (এই সংস্করণ) |
|---|---|---|
| চালাতে | `চালু করুন.bat` | `index.html` ডাবল-ক্লিক |
| জায়গা | ৩২৯ MB (একটি ফাইল) | ২৩৭ MB (১৩৪৯টি ফাইল) |
| পুরো জেলায় নাম খোঁজা | পারে | পারে না (এলাকা ধরে) |
| ওয়েবে তোলা | কঠিন | সহজ |

## লুকানো ফিচার — সংখ্যার রিপোর্ট

সাধারণ ব্যবহারকারী দেখতে পান না। খুলতে হয়:

| যেখানে | যেভাবে |
|---|---|
| কম্পিউটার | `Ctrl` + `Alt` + `R` |
| মোবাইল | উপরের পট্টির মানুষ-আইকনে ৩ সেকেন্ডের ভিতরে পরপর ৫ বার চাপ |

খুললে ফরমের উপরে দুটো বোতাম আসে — **ভোটার অনুসন্ধান** ও **সংখ্যার রিপোর্ট**।
একবার খুললে ব্রাউজার মনে রাখে; বন্ধ করতে আবার একই কাজ।

### রিপোর্টে কী থাকে

রিপোর্ট মোডে **কোনো ঘরই বাধ্যতামূলক নয়** — জেলা তো বসানোই থাকে, তাই সরাসরি
"রিপোর্ট দেখুন" চাপলেই পুরো জেলার আসনওয়ারি হিসাব আসে। যত নিচে বাছবেন,
ভাগও তত নিচে নামবে:

| যা বাছবেন | যেভাবে ভাগ হবে |
|---|---|
| শুধু জেলা | আসনওয়ারি |
| + আসন | উপজেলাওয়ারি |
| + উপজেলা | ইউনিয়নওয়ারি |
| + ইউনিয়ন | এলাকাওয়ারি |

প্রতিটি সারিতে মোট · পুরুষ · নারী · হিজড়া · বয়সভিত্তিক চারটি ভাগ
(১৮-২৫, ২৬-৪০, ৪১-৬০, ৬০+), নিচে যোগফল। উপরে সারাংশের বাক্সে শতকরা হিসাবও।

**এলাকার সারিতে ক্লিক করলে** ওই এলাকার ভোটারের তালিকা খুলে যায়।

বয়স হিসাব হয় তালিকা প্রকাশের দিন (২৪/১১/২০২৫) ধরে — তাই সরকারি তালিকার
সাথে মেলে এবং সময়ের সাথে বদলায় না।

রিপোর্টের ডেটা `data/<জেলা>/report.js` — মাত্র ৪৭ KB, তাই সাথে সাথেই আসে।
